Dieses Projekt soll mich an bestimmte Ereignisse oder Todos erinnern.

* Die Configuration soll über einfache yaml ablaufen. Ein Ordner, in dem mehrere yaml liegen,  die ein oder mehrere Ereignisse enthalten können.
* Eine Erinnerung kann entweder periodisch (zB. jeden Freitag um 18:00) oder einmalig zu einem Zeitpunkt erfolgen.
* Die Erinnerung soll über Telegram erfolgen. Die erinnerungsnachricht sollwiederholt werden bis bestätigt wird, dass es erledingt ist.
* Das programm ist für mich persönlich und soll einfach über ein docker compose up gestartet werden können.
